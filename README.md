## Descripción del proyecto

**Rutas Gastronómicas** es una aplicación móvil desarrollada con **Expo y React Native** que permite:
- Visualizar **platos típicos por zona y nivel de picosidad**.
- Marcar platos como **favoritos** (sincronizados con Firebase).
- **Abrir la app nativa de mapas (Google/Apple)** para ver cómo llegar.
- Mantener datos locales offline gracias a un **dataset de respaldo**.

El enfoque está en una experiencia **simple, rápida y visual**, pensada para **turistas o locales curiosos** que buscan explorar la gastronomía paceña.

---

## Problema y motivación

La información gastronómica está dispersa entre redes sociales, recomendaciones orales y publicaciones no organizadas.  
**No existe una app centralizada que indique dónde comer y cómo llegar.**

Por eso nace **Rutas Gastronómicas**, una solución que:
- Muestra en mapa platos y zonas.
- Permite filtrar por picosidad.
- Te guía al lugar típico con **un solo toque**.

## Demo funcional

**Pasos de la demo:**
1. Iniciar app → Splash / Onboarding.  
2. Permitir acceso a ubicación.  
3. Ver el mapa con marcadores.  
4. Aplicar filtros.  
5. Tocar un marcador → abrir “Ver en mapa”.  
6. Agregar un plato a favoritos.  
7. Revisar favoritos guardados.
